# Code of conduct

This project follows the ideas of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standard

- Be kind and patient. Many people here are parents who write code in their free time.
- Talk about the code and the idea, not about the person.
- Accept that other people have other opinions and other levels of experience.
- No harassment, no insults, no sexual language or images, no political attacks.
- Never publish private data of another person: names of children, schools, addresses, phone numbers, messages or grades. This rule also applies to issues, pull requests and logs that you paste.

## Scope

The rules apply in the issues, pull requests, reviews and every other project space.

## Report a problem

Tell a maintainer in private: use the report function of the repository host on the comment or the profile, or the private report form in the "Security" tab. Maintainers keep the name of the reporter private.

## What maintainers do

Maintainers can edit or remove comments, commits and issues that break these rules. They can block a person from the project for a time or permanently.
